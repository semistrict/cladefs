# Agent-name words

`adjectives.txt` and `nouns.txt` are the word lists `scripts/agent-name.py` picks a worktree's
adjective-noun name from. They are petname's small lists, `usr/share/petname/small/adjectives.txt`
and `names.txt` (animals), unchanged, from https://github.com/dustinkirkland/petname at commit
d263497a655beed5577f9592d766702194a4f2df: Copyright 2014 Dustin Kirkland, Apache-2.0 (`LICENSE`).
