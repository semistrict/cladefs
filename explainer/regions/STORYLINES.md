# Storylines: many regions, cells across buckets

The one idea: **each cloud region gets its own bucket, and every cell's ID carries its bucket's
number, so every request goes straight to the right bucket.** The worked example: a sandbox in
europe-west1 whose disk is one cell, `0x0002 000005 000009`, at home in bucket 2.

Recommended: **A. An ocean away**, because it opens on a wait a stranger feels (a sandbox's trips
across an ocean) and the whole film answers it with one number.

## A. An ocean away (recommended, built)

Device: a character does the work (a sandbox, its cell, two pails) in **one frame that rebuilds**:
the same two cloud regions and the ocean between them stay put while the story changes what is in them.

A sandbox in Europe restores its disk from a bucket in Virginia, and every one of its 11 round trips
crosses the ocean; the counter climbs while the sandbox frowns. Then each cloud region gets its own
numbered pail, the cell shows the number it carries and its trips stay next door; another cell's
read of its parent in bucket 1 finds that bucket by number, with this host's own credentials; parts that must cross do so once for the region, and peers never
cross. Mirrors are shown, stamped "in progress". The close returns to the hook: the trips stay home.

- First 2 s: lilac felt, two cloud regions with an ocean between; a pail pops in us-east-1, a sandbox
  in europe-west1 blinks, "One bucket, an ocean away" pops word by word.
- Beats: hook (11 trips across) → a bucket per cloud region, numbered from the root → the number in
  the cell's ID → the number finds the bucket → once across, shared at home, peers stay home →
  in progress: forks across and mirrors → "Remember the ocean?", the trips stay home.
- Look: the overview's felt, plum ink, Nunito titles; cloud regions as darker felt patches; the
  accent only on bucket numbers.
- Sound: the overview's ukulele bed, its last chord on the cell's landing at 70 s; pops on trips
  and badges.

## B. The registry's postcard (not built)

Device: one object across places: the registry, drawn as a postcard, is written at the root bucket
and mailed to every bucket's root; each host reads its own copy. Form: a flight across one map, each
cloud region a stop on the route. Strong on the registry, weak on why a viewer would care: it never
shows a sandbox waiting.

- First 2 s: a postcard stamped "bucket 1" lands in a pail.
- Beats: format → add → the card copied to each root → a host reads it → a read routed.
- Look: felt map, postcards in butter with plum ink. Sound: the bed; a paper flick per delivery.

## C. Sixteen bits (bold, not built)

Device: the object is the explanation: an endless zoom into one cell ID until its top 16 bits fill
the frame and turn into a signpost; each zoom out lands in a new place the number sends you. Form:
an endless zoom. Striking, but abstract: a stranger meets bits before a reason.

- First 2 s: a fuzzy critter wearing a long hex tag; the camera dives into the tag's first four digits.
- Beats: the ID → the number → the registry → the bucket → the part cache → peers → back to the critter.
- Look: the felt, giant JetBrains Mono digits. Sound: the bed, a whoosh on each zoom.
