# Measurements

Each run's write-up: a page here, or the `.md` files of its directory (`note.md` what it was for,
`comparison.md`, `ab.md` or `nightly.md` what it found).

Only the `.md` files are tracked, and the nightly's `night.json` (`.gitignore`). A run's raw output
(logs, JSON, counts) stays in this directory on the host that made the run. Raw output recorded
before 2026-11-27 is in git's history, last at `354f79021`: links to it from older write-ups no
longer resolve here.
